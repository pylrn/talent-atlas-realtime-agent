# Lightweight Admin UI Plan

## Goal
Add a small FastAPI-hosted admin interface at `/ui` so the project can be tested without external frontend tooling.

## Scope
- Show database health, record counts, and embedding/search settings.
- Run regular and orchestrated search from the browser.
- Browse candidates, documents, and chunks without exposing vector payloads.
- Add, edit, and delete candidate records.
- Ingest and delete candidate documents.
- Document the local workflow in `how_to_use.md`.

## Out of Scope
- Authentication and role-based access.
- Large dataset import UI.
- React/Vite/Node build tooling.
- Production admin hardening.

## Verification
- Add focused tests for admin helper behavior.
- Run pytest and ruff.
- Smoke-test `/ui` and admin endpoints against the local server.
